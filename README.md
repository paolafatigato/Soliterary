# Soliterary
Standalone copy (2026-11-09) of the book's story-solitaire game. No dependencies, no server: open index.html (or serve the folder).
- engine.js rules + solver · stories.js / levels.js / classics.js stories · grammar.js which cards fit · script.js UI · style.css graphics
- The school class game (class.js, online.js, Firebase of the textbook) was NOT copied; script.js still has an unused startClass hook.
- classics.js = whole books in 5 sentences; chapters.js = ONE SCENE per story, sentences of 1-4 cards (see grammar.js header).
